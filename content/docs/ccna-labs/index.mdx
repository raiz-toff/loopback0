## Lab environments

Run these topologies using one of the following network emulation platforms:

* **Cisco Modeling Labs (CML):** Direct Cisco reference platform with native IOL and IOSv images.
* **Cisco Packet Tracer:** Lightweight simulator for initial syntax and basic topology validation.
* **GNS3 / EVE-NG:** Multi-vendor emulation environments for connecting Cisco IOS to Linux and server endpoints.

Every lab provides a topology diagram, CLI configuration commands, and output verification steps.
