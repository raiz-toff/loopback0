Comma is a **privacy-first earnings tracker**. I built it for gig workers. This includes people who deliver for DoorDash, Uber Eats, and similar services. 

Comma has the following functions:
- It tracks your shifts with live GPS.
- It separates your active delivery miles from dead miles.
- It logs your expenses.
- It calculates tax set-asides for your market. (Supported markets: US, Canada, UK, and Nepal).

The application operates locally. It requires no user account. It uses no backend server. Your data stays on your device. You can choose to back up your data to Google Drive with encryption.

Comma has two versions. Both live in the same [repository](https://github.com/raiz-toff/Comma) and use the same backup format:

- **Web app** (`web/`): The original Progressive Web App (PWA). It works offline. It uses Vanilla JavaScript and IndexedDB. It runs only in your web browser.
- **Phone app** (repository root): The native Android application. I built it with Expo and React Native. It includes GPS shift tracking, multi-vehicle support, analytics, and reports.
