The MileWage mark is **Coin Road**: a coin crossed by a climbing road with a dashed centre line. The coin stands for the wage and the road for the mile. The mark carries no currency sign, so it works in every country.

The decision was made on 2026-11-08.

Lane yellow seeds the Material Design 3 colour scheme for both the web app and the Android app. In that scheme it holds the `primary-container` role.

Yellow on white has a contrast ratio of about 1.6:1. On light backgrounds, Asphalt is the main colour and yellow appears only inside the mark.

Earned green and Spent red are reserved for money values in the app. Neither appears in a logo. Blue is unassigned.

## Typography

The wordmark is Geist Bold (700), upper case, with 0.2 em tracking, converted to outlines. The SVG files do not need the font installed.

Geist is used only in the artwork. The web app sets text in Roboto Flex, and the Android app uses the system font.

## Usage rules

| Rule | Value |
|---|---|
| Clear space | One quarter of the symbol height on every side |
| Minimum size, symbol | 16 px with the small variant |
| Minimum size, lockup | 120 px wide |
| Adaptive icon | Artwork at 56 dp inside the 66 dp safe zone |
| Notification icon | One colour with transparency |

Do not stretch, rotate or outline the mark. Do not add shadows or gradients. Do not place the colour version on a photograph. Do not set the wordmark in another font.
