## Lab objectives
- Configure Windows Server roles including Active Directory, DHCP, and Group Policy.
- Deploy software over the network using PowerShell remoting.
- Write PowerShell scripts for Active Directory administration.
- Build a WinForms GUI dashboard entirely in PowerShell.
- Create input validation scripts for IPv4 addresses.
